# Cisco Packet Tracer Networking Labs

Hands-on Cisco Packet Tracer labs focused on switching, VLANs, redundancy, and Layer 2 security.

## Projects

| Folder | Topics |
|---|---|
| `01-VLAN-and-Inter-VLAN-Routing` | VLANs, access/trunk ports, 802.1Q, Router-on-a-Stick, SVI, VTP/DTP |
| `02-EtherChannel-LACP` | LACP, Port-Channel, link aggregation and redundancy |
| `03-STP-RSTP-Redundant-Switching` | Root bridge election, STP port roles, loop prevention and failover |
| `04-PortFast-and-BPDU-Guard` | Edge-port protection and BPDU Guard |
| `05-Port-Security` | Sticky MAC learning, violation detection and recovery |

Each project folder contains its own explanation, configuration commands, verification steps, and Packet Tracer activity where available.

## Learning approach

Each lab is built and tested in Cisco Packet Tracer. Screenshots and CLI outputs are added as evidence of the configuration and test results.
